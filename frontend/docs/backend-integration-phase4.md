# 前端后端联调工作区（阶段 4）

现有首页仍是完整的前端演示工作区，使用本地 Pinia 数据；它没有被偷偷改成“看似已接后端”的假状态。真实接口使用独立入口：

`http://127.0.0.1:5173/connected.html`

## 联调入口行为

- 首次打开先获取 CSRF 令牌，再尝试刷新 HttpOnly Cookie；未登录的 401 是匿名初始状态，不会生成演示账号。
- 登录成功后，访问令牌只保存在运行时内存；页面刷新由刷新 Cookie 恢复会话。
- 所有写请求都带 `X-XSRF-TOKEN`，网络失败不会自动重复提交；401 只对当前请求做一次刷新后重试。
- 页面角色来自服务端返回的 `roleCode`，没有前端角色切换按钮。服务器仍是最终权限边界。
- 员工课程页请求 `/api/v1/employee/courses`，管理员课程页请求 `/api/v1/admin/courses`；课程创建/编辑使用版本号处理并发冲突。
- 员工点击课程卡片的“查看详情”后读取章节和资源摘要；首次学习可报名，完成章节会调用进度接口并刷新课程汇总进度，重复报名和重复完成均可安全重试。
- 管理员课程详情可上传和删除资源；员工资源按钮通过带权限的 Blob 请求读取内容，视频使用原生播放器，PDF/图片内嵌预览，普通附件提供下载。
- “题库与试卷”入口已接入真实考试接口：管理员可以查看/新增题目、从题库创建 100 分草稿并发布；员工可以查看分配的考试、答题、提交并看到服务端判分和解析。
- “培训计划”入口已接入真实计划接口：管理员可以绑定已发布课程和考试、发布计划；员工可以查看本人计划，并按课程完成和考试通过结果刷新计划进度。
- “培训档案 / 数据分析”入口已接入汇总接口：员工查看个人课程、考试、计划和最近记录；管理员查看启用员工、课程完成率、考试通过率和计划完成率。
- “结业证书 / 我的证书”入口已接入证书接口：培训计划完成后自动签发唯一证书编号，员工查看本人证书，管理员查看已签发记录。
- 证书卡片支持浏览器打印和文本下载；管理员数据分析页使用 ECharts 展示课程完成率、考试通过率和计划完成率。
- 个人资料页面将 `version` 原样提交，密码修改成功后服务端撤销所有刷新会话并退出当前工作区。

## 前端命令

```powershell
pnpm dev
pnpm typecheck
pnpm build
```

Vite 的 `/api` 代理默认指向 `http://127.0.0.1:8081`，可用 `VITE_API_PROXY_URL` 覆盖。生产部署时应由同源网关转发 `/api`，并在 HTTPS 下开启安全 Cookie。
