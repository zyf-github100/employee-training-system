# 统一真实管理端验收

日期：2026-11-02，Pacific/Honolulu。使用 Windows、Java 17、MySQL 8.4 独立临时实例、真实 Spring HTTP API、Vite 和 Chromium。未连接原有业务数据库。

## 入口与交付范围

- 主入口 `/#/admin/dashboard`，管理员登录及已登录管理员访问根路由默认进入管理工作台。员工默认进入学习首页。
- 管理侧栏包含工作台、课程、培训计划、题库、考试、组织员工、培训档案、数据分析、证书和个人资料；共用现有真实会话，可进入员工学习界面。
- 旧 `/connected.html` 兼容跳转到主入口，保留原有演示入口 `/demo.html`。
- 新增课程/章节资源、题库编辑、显式选题及分值配置、员工培训档案页面。计划名单支持搜索、20 人分页、本页选择/取消、跨页保留及发布人数确认。组织员工等既有功能复用真实组件。
- 档案新增 `GET /api/v1/admin/employees/{id}/archive`，需要配套更新后端；服务端按当前账号数据范围校验，返回课程、考试、计划及最近 10 条记录。

## 自动化结果

- `pwsh -NoProfile -File backend/scripts/isolated-mysql.ps1`：6 个测试类、60 项通过，失败/错误/跳过均为 0。新增 2 项档案访问测试覆盖本部门及下级、范围实时变更为本人、跨范围拒绝、超级管理员访问、员工与匿名拒绝。
- `npm run test:session`：4 项通过。
- `npm run test:training`：23 项演示业务回归通过，不作为真实接口验收依据。
- `npm run build`：Vue/TypeScript 检查和三入口生产构建通过。仍有现有 ECharts 分包超过 500 kB 的提示。

## 浏览器实际验证

1. 管理员通过主登录页进入管理工作台，使用真实统计接口读取数据；刷新会话、访问根路由仍进入管理首页。
2. 从页面新建“管理端验收课程”，添加“管理端验收第一章”及正文，上传 PNG 图片；刷新页面后课程、正文和资源仍存在，打开图片预览成功。
3. 新增单选题并在界面选择正确答案，保存后再次编辑解析。手动选取该题和一条判断题，均分成两题各 50 分，创建 100 分草稿，查看快照并确认发布成功。
4. 为名单分页构造 25 名虚构员工（通过真实 API 创建，仅作为浏览器测试夹具；不作为员工新增页面验收）。加上本地示例员工共 26 人，第一页面选择 20 人，第二页选择 1 人，计数保留为 21。创建计划后确认弹窗显示 21 人，发布后列表显示“21 名参训员工”。
5. 档案页读取示例员工的课程/考试/计划汇总和真实计划记录，未显示预估观看时长为实际学习时间。
6. 390×844 视口逐页读取 10 个管理页面，主文档宽度均为 390，无页面横向溢出；没有管理接口失败或页面业务错误。验证手机导航打开、选择管理首页后关闭。
7. 员工登录后手动访问 `/#/admin/employees` 被重定向至学习首页；真实管理员档案接口请求返回 403。
8. 旧 `/connected.html` 跳转到 `/#/admin/dashboard`，管理员可通过主入口继续使用管理功能。
9. 数据分析图表刷新后重新挂载，画布仍为 1100×280；折叠侧栏时画布跟随容器变化，避免刷新后空白及侧栏调整后宽度失配。

本轮本地预览的前端为 5175、API 为 18082，使用临时隔离数据库。复现时先设置 `TRAINING_CORS_ORIGINS=http://127.0.0.1:5175` 并运行隔离脚本 `-Mode serve -Port 33319 -ApiPort 18082`，前端设置 `VITE_API_PROXY_URL=http://127.0.0.1:18082` 后执行 `npm run dev -- --port 5175`。也可沿用默认 5173/8081 开发配置。
