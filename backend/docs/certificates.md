# 证书交付与运维

数据库迁移 V15 为证书增加签发快照、独立验真码、撤销原因/操作人和版本。自动结业统一调用 CertificateRepository.issue；只接受已完成的分配，重复完成不改变原编号、签发时间、快照、验真码或撤销状态。

## 配置

- `TRAINING_PUBLIC_WEB_URL`：对外可访问的前端地址，例如 `https://training.example.com`。PDF 内的可点击二维码和管理页分享链接使用同一地址。不根据请求 Host 自动生成；生产未配置时 PDF 返回 503，避免签发不可用的验真链接。local/test 默认 `http://127.0.0.1:5173`，使用其他端口时必须明确配置。
- `TRAINING_CERTIFICATE_TIME_ZONE`：PDF 日期时区，默认 UTC，例如 `Asia/Shanghai`。数据库继续保存 UTC 时间点。上线签发前确定该配置，避免不同环境产生不同日期展示。
- 已打包中文字体，无需服务器安装字体。字体来源、许可和复现步骤见 `src/main/resources/fonts/README.md`，分发时保留 OFL 许可。

## 接口

| 接口 | 行为 |
| --- | --- |
| `GET /api/v1/employee/certificates/page` | 本人的分页证书，pageNo/pageSize、keyword、status（VALID/REVOKED） |
| `GET /api/v1/admin/certificates/page` | 当前人员授权范围内的分页证书；关键词匹配编号/签发姓名/工号/计划 |
| `GET /api/v1/{employee或admin}/certificates/{id}/pdf` | 真实 PDF 附件，no-store；本人或当前管理员范围检查；撤销后下载带无效说明与水印的版本 |
| `POST /api/v1/admin/certificates/{id}/revoke` | JSON `{ "reason": "复核原因", "version": 0 }`；必填原因最大 500 字，当前授权范围检查 |
| `GET /api/v1/certificates/verify?code=...` | 无需登录，以 32 字节安全随机值对应的 64 位十六进制码查询；不支持按可预测的编号公开检索；no-store |

原有员工/管理员证书列表接口继续兼容。撤销与人员范围变更共用数据库锁；版本冲突返回 409。同原因重试返回原记录，不覆盖时间/操作人；不同原因重复撤销返回 409。撤销后无法通过重复结业恢复。管理员 PDF 下载、撤销及失败结果进入现有操作审计；不保存请求正文、完整查询串或验真码。

## 历史数据和验真边界

旧证书在 V15 升级时冻结当时的姓名、工号、计划名称和企业名称，标为 LEGACY；无法从旧表还原过去被修改的信息，验真页和 PDF 明确说明升级时固化。原编号、签发时间及撤销状态保留；缺少完成日期时采用原签发日期。证书持有人不能被物理删除，以保留可核验记录。

验真链接持有人能读取证书编号、获得人姓名、部分隐藏的工号、培训计划、签发单位、日期及当前状态；不会返回用户 ID、完整工号、撤销原因或操作人。链接属于可分享凭证，应按需交付；页面请求不发送登录凭据，也不把验真码放入 Referer。管理员和员工本人可在授权列表中读取撤销原因。

PDF 是带在线核验的培训结业文件，未接入 CA 数字签名、电子签章或时间戳。已下载文件不能被远程改写，当前有效状态以在线验真为准。PDF 现场生成并嵌入中文字体和二维码；不支持的字符会明确报错，不能静默改写姓名。暂无公开验真限流、生产压测或外网扫码可达性验收；上线时由网关设置适当限流并验证正式域名与 TLS。
