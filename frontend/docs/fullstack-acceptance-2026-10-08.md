日期：2026-10-08。范围为本轮交接文档的前三个开发优先项；不代表生产上线验收。

## 环境与入口

- Windows / Java 17.0.20.1 / 本机 MySQL 8.4.9 / Spring Boot 3.5.16。
- `backend/scripts/isolated-mysql.ps1` 启动独立临时 MySQL，随机 root 口令与 `training_qa` 库。自动化测试端口 33317，浏览器验证另用 33318 / API 18081。
- 浏览器由 Playwright CLI 驱动 Chromium；前端测试地址 `http://127.0.0.1:5174/`，通过 Vite 代理连接 18081；API 的测试 CORS 配置显式允许该来源。
- 正常开发主入口 `/`，演示入口 `/demo.html`，真实管理入口 `/connected.html`。主员工代码在 `src/training/live/`。
